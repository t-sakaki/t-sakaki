# 榊原平 (Taira Sakakibara)

**シビックテック × SDGs** — 愛知県安城市を拠点に、「市民の市民による市民のためのサービスづくり」をテーマに活動する市民活動家・プログラマーです。SDGs の達成を大切な目標とし、#プラネットポジティブ を掲げて、地域の課題を AI とシビックテックで解決するプロダクトを開発しています。

*Civic activist & developer from Anjo, Aichi, Japan — building civic tech and AI agents for local problems and the SDGs.*
